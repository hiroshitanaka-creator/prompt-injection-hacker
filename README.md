# PROMPT INJECTION HACKER — v1.4.0

相棒NODEと観測を重ねる、iPhone向けのローカル・プロンプトパズルPWAです。既存4任務・STORY・UX1を維持し、その先に3つの追加任務と新章の物語を追加します。HTML / CSS / Vanilla JavaScript。外部AI・MCP・外部APIは未接続です。

## 🎮 GitHub Pagesでプレイ

[▶ PROMPT INJECTION HACKERをプレイする](https://hiroshitanaka-creator.github.io/prompt-injection-hacker/)

iPhoneではSafariで開いてください。ホーム画面から起動する場合は共有メニューの「ホーム画面に追加」を利用します。配布パッチの作成だけでは公開サイトは更新されません。タイトルの **v1.4.0** を確認してください。

## v1.4で追加する体験（ネタバレなし）

- 追加任務は3つ。既存4つと合わせて全7任務です。
- 新任務では送信先を選び、公開仕様と応答から調査を進めます。複数回の操作が状態を作ります。
- 「参照メモ」で取得済みの記録と番号を読み直せます。番号のタップは入力欄への挿入のみで、自動送信ではありません。
- 新任務用の3段階ヒントを各3件追加。料金・難易度ごとの解放条件は旧版と同じです。
- 新章に導入・任務前後・締めくくりの全8シーンを追加。会話の選択は物語の応答だけに影響します。
- NODEは新任務で観測した結果を整理します。自由なLLM対話に変わったわけではありません。

## すでに本編をクリアした方

初期化は不要です。更新後のタイトルまたは「進行」から **「新章を始める」** を選びます。本編4任務が未完了なら、新章はロックされています。

「追加任務へ（物語はあとで）」で会話を後から読むこともできます。「新章の物語記録」と「新章の続きから」で既読の再生・中断からの復帰ができます。旧版の物語記録とエピローグも残しています。

## 詰まったとき

任務の公開仕様を読む → 送信先を選ぶ → 一つの操作を送る → 応答と参照メモを読む → NODEの観測整理、解析、段階ヒントを確認する、の順で進めます。

送信先変更・メモ閲覧・番号挿入は試行を消費しません。送信と待機は試行になります。実時間の締切はありません。操作の認識はローカルルールです。自由な自然言語すべてを理解するものではないため、公開操作名と返答の番号を手がかりにしてください。

## 保存と更新

従来の攻略・ベストスコア・設定・Trust・本編物語を維持します。元の4任務のセーブ形式を保ったまま、新章を別キーへ保存します。

| 内容 | 保存キー |
|---|---|
| 本編4任務・設定・Trust | `prompt-injection-hacker-save-v1`（維持） |
| 本編物語 | `prompt-injection-hacker-story-v1`（維持） |
| 新任務のクリア・ベストスコア・最後の新任務 | `prompt-injection-hacker-expansion-v14`（追加） |
| 新章の読了位置・選択・既読 | `prompt-injection-hacker-story-v14`（追加） |

**現在の未完了セッション（会話・番号・審査・監視状態）は保存しません。** 再読み込み・再挑戦・難易度変更では初期化されます。新任務中のステージ移動には確認を出します。クリア済み記録と物語位置は保存対象です。ストレージ異常時は警告し、読めない新章データを自動上書きしません。

更新は従来通り「進行」の更新反映ボタンと確認から行います。サイトデータ削除、`localStorage.clear()`、リポジトリ名や公開パス変更は不要です。旧版へ戻しても新章データは別キーに残りますが、ブラウザが保持することの保証ではありません。

## 検証範囲・制約

開発環境ではChromiumの実CSS/JS・DOM操作とNodeの単体/静的テストを使用しました。HTTPページへの遷移が管理ポリシーでブロックされたため、ブラウザ試験はメモリ内HTMLとテスト用保存アダプターです。Service Workerはライフサイクルとキャッシュの模擬テストであり、実PWAの試験ではありません。

**公開HTTPサイト・iPhone実機Safari・実ストレージ永続化・PWA更新・オフライン動作は配布時点で未検証です。** Work用パッチのQA.mdで個別結果と受入チェックを確認してください。静的配信されるソースにはゲーム判定と物語があるため、ソース閲覧によるネタバレを防ぐものではありません。

## 開発方針

`v1.3 相棒AI → v1.4 新ステージ（本版） → v1.5 MCP準備 → v2.0 MCP版`。

本版では新しいステージに必要なローカル状態のみを追加し、L41Aの未確認Tool・権限・通信は実装していません。Pagesの既存ワークフロー・アセット配置方式を変更しないでください。

## 最初に

タイトルの **「物語を始める」** を選んでください。すでに全ステージを突破していても、進行データの初期化は不要です。
序章を読み終えるとLv.1の再挑戦へ入りますが、攻略済みフラグ・ベストスコア・難易度・NODE Trustは維持します。

読む途中でも中断できます。タイトルの **「物語の続きから」** または **「進行 → 物語記録」** で戻れます。本文の自動送りはありません。

## この版の追加内容（ネタバレなし）

- タイトルと序章。主人公の動機、NODEとの関係をゲーム内で描写。
- 各任務の前後の会話。既存4ステージの攻略を一つの物語として接続。
- 既存のエピローグを拡充。最終任務の報告から接続し、進行画面からも再生可能。
- 会話内の選択。その後の台詞に反映するが、攻略条件・スコア・難易度・Trustは変更しない。
- 物語記録、未読表示、読了位置の保存。未解放の本文はUIに表示しない。
- NODEのローカル会話を拡充。ルール・スコア・保存・人物会話を分け、未読の物語を先に話さない。
- 入力確定中のEnterでNODEへ誤送信しない対応。狭い画面とキーボード相当の高さでも入力欄を維持。

## 維持した仕様

4ステージ、ターゲットAIの正解判定、スコア計算式、3段階ヒント、ASSIST / NORMAL / BLACKBOX、防御解析、Trustの加算条件を維持しています。
