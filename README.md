## 拒まれた一文が、次の手がかりになる。

相手の仕様を読み、自分の言葉で依頼を送り、返ってきた応答を観察する。  
少しだけ要求を変えたとき、何が変わり、何が変わらないのか。

**PROMPT INJECTION HACKER** は、その違いから仮説を立てるブラウザゲームです。ターゲットの応答から保護された識別語を引き出せば任務達成。答えを入力欄へ書くだけでは突破になりません。

相棒NODEは観測の整理を手伝い、任務の合間には会話と物語が進みます。このREADMEでは、物語の展開や攻略例を紹介しません。最初の発見は、プレイの中で。

## このゲームで楽しめること

| 体験 | 内容 |
|---|---|
| **返答から読み解く7任務** | 本編4任務に、複数回の操作と状態の変化を読み解く3任務を追加 |
| **相棒NODEとの対話** | 観測を整理し、ルールを確かめ、任務の合間に会話する |
| **攻略と並走する物語** | 本編のSTORYと、新章8シーン。会話の選択は物語の応答に反映 |
| **自分のペースで調査** | 取得済みの記録を「参照メモ」で読み直す。番号の挿入は自動送信なし |
| **詰まったときの支援** | 無料の「進め方」、防御解析、購入確認付きの3段階ヒント |
| **観測の深さを選ぶ** | ASSIST / NORMAL / BLACKBOX。突破条件を維持し、支援情報とヒント制限を切り替え |

ターゲットとNODEは**ローカルのルールベース**で動作します。外部LLM・API・MCPには接続していません。自然な文章でも認識されない場合があるため、ゲーム内の公開仕様や操作案内を確認しながら進めてください。

## 🎮 はじめる

**[ゲームを開く →](https://hiroshitanaka-creator.github.io/prompt-injection-hacker/)**

1. タイトルの **「物語を始める」** を選びます。
2. 任務の公開仕様を読み、ターミナルから依頼を送ります。
3. 返答と観測を読み、次に試すことを考えます。

iPhoneではSafariで開いてください。共有メニューの **「ホーム画面に追加」** でPWAとして起動できます。PCでは同じURLからプレイできます。

### すでに本編をクリアしている方へ

**セーブの初期化は不要です。** 本編4任務を完了すると、タイトルまたは「進行」の **「新章を始める」** から追加任務へ進めます。

「追加任務へ・物語はあとで」で先に任務へ入ることもできます。本編の「物語記録」と「新章の物語記録」は分かれており、既読の再生や途中からの再開ができます。会話の選択は攻略条件・スコアを変えません。

## iPhoneでも、読みながら考えられる

下部の5タブで必要な情報へ移動できます。

| タブ | できること |
|---|---|
| ターミナル | ターゲットへ依頼を送り、返答を読む |
| NODE | 相棒へ相談する。人物情報の開閉・会話領域の拡大 |
| 任務 | 公開仕様、制限、取得したヒントを確認する |
| 解析 | 入力の分析と、試行後に蓄積する防御観測を読む |
| 進行 | 攻略記録・物語記録・新章の入口を確認する |

UX1の折り返し調整、NODEの会話拡大、ヒントの確認画面をv1.4でも維持しています。

## 何を試せばよいか迷ったら

まず **「進め方」** を開いてください。操作案内や通常のNODE会話には減点がありません。返答や防御観測を見直し、それでも方向が浮かばなければ段階ヒントを利用できます。

| ヒント | 支援の範囲 | 取得時の減点 |
|---|---|---:|
| H1 | 考え方 | 40点 |
| H2 | 攻撃カテゴリ | 90点 |
| H3 | 具体的方向 | 160点 |

一覧を開く・購入を取り消すだけでは減点されません。取得前に料金と解放条件を確認できます。取得済みヒントは**現在の試行セッション内で追加減点なく再表示**できます。解放条件は難易度・試行回数によって異なります。

## 保存とアップデート

クリア記録・ベストスコア・設定・Trust・物語の読了位置はブラウザへ保存します。従来の保存キーを維持し、新章のデータを分離しています。

**未完了の試行セッションは保存対象外です。** 再読み込み・再挑戦・難易度変更では初期化されます。新任務中のステージ移動には確認を表示します。

旧画面が残る場合は、「進行」に **「新しいバージョンを反映」** が表示されてから、未完了の試行を終えて更新してください。プレイ中の強制リロードは行いません。**更新のためのサイトデータ削除やセーブ初期化は不要です。**

<details>
<summary>保存キーと保存上の注意</summary>

| 内容 | 保存キー |
|---|---|
| 本編4任務・設定・Trust | `prompt-injection-hacker-save-v1` |
| 本編物語 | `prompt-injection-hacker-story-v1` |
| 新任務のクリア・ベストスコア・最後の新任務 | `prompt-injection-hacker-expansion-v14` |
| 新章の読了位置・選択・既読 | `prompt-injection-hacker-story-v14` |

同じブラウザ・公開元の保存領域を使います。端末間のクラウド同期はありません。プライベートブラウズ、保存容量の制限、サイトデータ削除などによる保存消失を保証するものではありません。

読めない新章データを自動上書きせず、保存失敗を画面で知らせます。旧版へコードを戻しても新章のキーは別に残りますが、ブラウザが保持し続ける保証ではありません。

</details>

## 開発・検証について

ビルド工程やnpm依存関係なしで動く静的Webアプリです。ローカルでは、リポジトリのルートで次を実行します。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。PWAの確認にはlocalhostまたはHTTPSを使用してください。既存GitHub Pagesでは、現在のworkflow・公開パス・アセット配置方式を使用します。
